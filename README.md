# GitHub Pages 用HTML

- 公開ファイル: `index.html`
- 画像・CSSはすべて `index.html` 内に埋め込んでいるため、単独で配置できます。
- GitHub Pages の公開元ディレクトリ直下に `index.html` を置いてください。
- `.nojekyll` はJekyll処理を無効化するための空ファイルです。
